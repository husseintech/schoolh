# إعداد حزم التعلم المخصصة

## ما تغيّر

- يطلب التوليد الصف المستهدف ومفهوم الدرس، ويقبل المعرفة السابقة ومقتطفًا من الكتاب ومدة الحصة ومستوى الطلاب.
- تُحفظ المواصفات داخل `ai_payload._brief` دون ترحيل قاعدة البيانات أو تعديل بيانات الطلاب والمعلمين.
- تتضمن الحزمة أهدافًا ومفاهيم وشرحًا وأمثلة محلولة وأخطاء شائعة وورقة عمل وخطة زمنية.
- يفحص الخادم البنية، ارتباط أسئلة الورقة بالأهداف، ومجموع زمن الحصة. هذا فحص اكتمال واتساق، وليس ضمانًا آليًا لصحة المادة أو مطابقتها للمنهاج.
- تبقى الحزمة بانتظار اعتماد المعلم. إجابات الورقة وخطة الحصة مخصصتان للمعلم.
- لا تستبدل الخدمة غياب النموذج أو نفاد الحصة بقوالب عامة. تبقى البيانات السابقة عند فشل التوليد.
- المصادر الخارجية نتائج بحث فعلية؛ ترتيب الكلمات ليس شهادة بالدقة أو برخصة الاستخدام المفتوحة. تُراجع قبل اعتمادها.

## Vercel: تفعيل النموذج

في إعدادات مشروع المدرسة، Environment Variables، أضف أو عدّل:

| الاسم | القيمة |
| --- | --- |
| `AI_PROVIDER` | `gemini` |
| `AI_API_KEY` | مفتاح صالح من Google AI Studio، من النوع Secret |
| `AI_MODEL` | `gemini-2.5-flash` أو نموذج يدعم JSON ومتاح للحساب |

أعد نشر المشروع بعد الحفظ. لا تضع المفتاح في المستودع أو رسائل الدعم. ظهور النموذج في لوحة مراقبة الذكاء الاصطناعي يؤكد وجود الإعداد فقط؛ نجاح طلب حقيقي يؤكد عمل الاتصال والحصة. لا يتضمن هذا التعديل شراء خطة أو مفتاحًا جديدًا.

مرجع المزود: https://ai.google.dev/gemini-api/docs/structured-output

## البحث الخارجي

البحث الافتراضي أصبح `open_catalog`: طلبات إلى API ويكيبيديا العربية وويكي الكتب العربية وويكيميديا كومنز. لا يحتاج مفتاح بحث أو بطاقة، ولا يستدعي Gemini. يتم حفظ روابط الصفحات وأوصاف قصيرة من نتائجها للمراجعة، ولا تُنسخ الملفات أو تُضمَّن الصور تلقائيًا. راجع ملاءمة العمر ودقة المحتوى وترخيص كل مادة في صفحتها.

تُنفذ الطلبات بالتتابع وبهوية تطبيق معلنة مع تخزين نتائج مؤقت لعشر دقائق حيث تتوفر ذاكرة الخادم. قد تتعذر هذه الخدمات أيضًا؛ عندها تبقى أزرار البحث الموجّه في متصفح المعلم متاحة. هذه الأزرار ليست نتائج بحث مسترجعة ولا تُحفظ كموارد تلقائيًا. يختار المعلم مادة مجانية مناسبة ويحفظ رابطها الحقيقي من النموذج الجديد، ثم يعتمدها لإظهارها للطلاب.

إذا كان إعداد `SEARCH_PROVIDER` القديم مضبوطًا يدويًا، غيّره إلى `open_catalog` لتفعيل المسار المجاني. لا تُضف بيانات دفع أو خدمة بحث جديدة. تبقى إعدادات Gemini الحالية كما هي وتخضع لحصة حساب Google.

للتوافق مع الحسابات القديمة فقط: Google Custom Search JSON API مغلق للعملاء الجدد؛ ليس مسار الإعداد المقترح لهذا المشروع. إعداداته القديمة:

| الاسم | القيمة |
| --- | --- |
| `SEARCH_PROVIDER` | `google` |
| `GOOGLE_CSE_ID` | معرّف محرك البحث |
| `GOOGLE_CSE_API_KEY` | مفتاح خدمة البحث |

تحقق من أهلية الخدمة وحصتها قبل إعدادها. مفتاح Gemini ليس بديلًا تلقائيًا عن إعداد خدمة البحث.

## تحقق بعد النشر

1. افتح درسًا من حساب معلمه وحدد الصف الرابع ونطاقًا دقيقًا (مثل الفاعل المفرد والضمة).
2. أنشئ الحزمة وتحقق من الأمثلة والإعراب والإجابات ومن مجموع زمن الخطة.
3. تحقق من أن الطالب لا يرى الحزمة المعلقة، ثم اعتمدها وتحقق من ظهور الأنشطة دون إجابات المعلم.
4. ابحث عن المصادر وتحقق من النتائج أو رسالة التعذر الصريحة وسجل الطلب.
5. من الخطة الأسبوعية اربط الدرس واضغط استخدام أهداف الحزمة المعتمدة، ثم راجع واحفظ.

الاختبارات الآلية تستخدم استجابات نموذج وبحث محاكية، ولا تثبت توفر مفتاح الإنتاج أو دقة مخرجات نموذج حي.
