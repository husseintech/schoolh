# مساعد المنهاج المعتمد

مساعد مستقل عن قسم **التعلم المفتوح**. التعلم المفتوح يبقى لنشر الدروس والأنشطة، بينما مساعد المنهاج يشرح ويجيب من صفحات كتب رسمية محددة، ويُلزم كل إجابة قابلة للإجابة بمرجع صفحة صالح.

## البنية

- `CurriculumSource`: إصدار كتاب واحد مع بصمة SHA-256 وحالة مسودة/منشور/مؤرشف.
- `CurriculumLesson`: فهرس الوحدات والدروس ونطاق الصفحة المطبوعة وصفحة PDF.
- `CurriculumLessonVideo`: روابط فيديوهات يوتيوب التي راجعتها الإدارة وربطتها بكل درس.
- `CurriculumPage`: النص القابل للبحث والوصف البصري وحالة المراجعة.
- `CurriculumConversation` و`CurriculumMessage`: محادثات الطالب والمراجع المستخدمة.
- `CurriculumAnswerCache`: إعادة استخدام الإجابة المطابقة للمصدر والدرس والسؤال لتقليل كلفة AI.

ملف PDF الأصلي يُرفع إلى Google Drive عبر أجزاء بحجم 2MB، مع مقارنة بصمته ببصمة ملف الفهرسة قبل بدء الرفع. لا يعتمد الاسترجاع أثناء السؤال على Drive؛ يعتمد على صفحات قاعدة البيانات، لذلك تظل الإجابة والمراجع النصية متاحة عند تعطل التخزين.

## تفعيل كتب الصف الرابع

1. انشر الكود وشغّل ترحيل قاعدة البيانات:

   ```bash
   python manage.py migrate
   ```

2. افتح **الإعدادات ← مصادر مساعد المنهاج** بحساب المدير.
3. استورد حزمة `JSON.GZ` لكل مادة. يبقى المصدر مسودة.
4. ارفع PDF الأصلي في بطاقة المادة. سيتحقق المتصفح من SHA-256 قبل الرفع.
5. راجع الصفحات المعلّمة بصريًا وأضف وصف الصورة أو المخطط عند الحاجة.
6. اضغط **نشر للطلاب**. نشر إصدار جديد يؤرشف الإصدار المنشور السابق للمادة نفسها.

## فيديوهات الدروس

من صفحة **مصادر مساعد المنهاج** يستطيع المدير اختيار المادة والدرس، ثم كتابة عنوان الفيديو
ولصق رابط YouTube. يحتفظ النظام بمعرّف الفيديو فقط بعد التحقق من النطاق، ويرفض الروابط
الخارجية أو أكواد التضمين. يظهر للطالب العدد الفعلي للفيديوهات المعتمدة، ويُشغّل اختياره داخل
نافذة المنصة باستخدام `youtube-nocookie.com`. حذف الفيديو من لوحة الإدارة يزيله فورًا من الدرس.

لن يرى الطالب أي مصدر مسودة أو مؤرشف، والنسخة الحالية لا تُتاح إلا لطالب مرتبط بصف يحمل اسم الصف الرابع أو الرقم 4.

## إعادة تجهيز كتاب

يحوي `docs/curriculum_grade4_term1.json` الفهرس المعتمد للكتب الأربعة. لتجهيز إصدار PDF مطابق:

```bash
python manage.py prepare_curriculum_source /path/to/book.pdf \
  --book math \
  --output /path/to/math.json.gz
```

المفاتيح المتاحة: `arabic` و`math` و`science` و`english`. تستخدم الأداة PyMuPDF إن كان مثبتًا، ثم ترجع إلى `pypdf`. إذا تغيّر عدد صفحات الكتاب تتوقف الأداة قبل إنشاء الحزمة حتى يُراجع الفهرس.

## الذكاء الاصطناعي

يستخدم المساعد إعدادات المزود الحالية (`AI_PROVIDER` و`AI_API_KEY` و`AI_MODEL`). طريقة `answer_curriculum_question` منفصلة عن مساعد الموقع العام، ولا تقبل إجابة قابلة للعرض دون معرّف صفحة من السياق المرسل. لا يُرسل اسم الطالب أو رقمه أو ملفه إلى المزود.
